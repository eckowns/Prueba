# Portafolio Profesional - Fernando Mardones

Este repositorio contiene el desarrollo de mi portafolio web personal, creado como parte de la evaluación para la carrera de **Ingeniería en Informática**.

## Tecnologías Utilizadas
* **HTML5**: Estructura semántica completa.
* **CSS3**: Diseño responsivo utilizando **Flexbox** y **CSS Grid**.
* **Git/GitHub**: Control de versiones y despliegue.

## Secciones del Sitio
1. **Sobre mí**: Resumen de perfil profesional.
2. **Habilidades**: Tabla técnica de conocimientos.
3. **Proyectos**: Galería con metodología de trabajo.
4. **Contacto**: Formulario de comunicación.
